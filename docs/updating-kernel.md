# Updating the Kernel

If you wish to update your kernel within PS4 Linux, here's how to do it.

1. Download the script:

   ```bash
   curl -fsSL -O https://gist.githubusercontent.com/GattoDev-debug/1b6ea6f543b7aa3a4d3c20ac5c606fe9/raw/ps4-kernel-updater.sh
   ```

   (Ha ha, I know, self promo. Shut it. :3)

2. Make it executable:

   ```bash
   chmod +x ps4-kernel-updater.sh
   ```

3. Run it as root:

   ```bash
   sudo ./ps4-kernel-updater.sh
   ```
